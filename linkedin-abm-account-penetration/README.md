## Run it in a chat

Attach your exports to a chat with Claude (or any assistant that can read a web page) and paste:

```text
Load the LinkedIn ABM Account Penetration skill from https://github.com/demandsense-labs/linkedin-ads-skills/tree/main/linkedin-abm-account-penetration and run it on the exports I've attached.
```

It gives recommendations only and changes nothing in your ad account or CRM.

**To keep it in Claude.ai:** download [linkedin-abm-account-penetration.zip](https://github.com/demandsense-labs/linkedin-ads-skills/releases/download/skill-files/linkedin-abm-account-penetration.zip) and upload it under **Customize → Skills → Upload a skill**.

## Run it in Claude Code

[Install the collection](../README.md#install), then call it by name or just ask for it, for example *"which of our target accounts are engaging"*:

```text
/linkedin-ads-skills:linkedin-abm-account-penetration
```

[`SKILL.md`](SKILL.md) holds the instructions the assistant follows.
