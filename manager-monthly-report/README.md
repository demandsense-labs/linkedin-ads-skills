## Run it in a chat

Attach your exports to a chat with Claude (or any assistant that can read a web page) and paste:

```text
Load the Manager Monthly Report skill from https://github.com/demandsense-labs/linkedin-ads-skills/tree/main/manager-monthly-report and run it on the exports I've attached.
```

It gives recommendations only and changes nothing in your ad account or CRM.

**To keep it in Claude.ai:** download [manager-monthly-report.zip](https://github.com/demandsense-labs/linkedin-ads-skills/releases/download/skill-files/manager-monthly-report.zip) and upload it under **Customize → Skills → Upload a skill**.

## Run it in Claude Code

[Install the collection](../README.md#install), then call it by name or just ask for it, for example *"prepare my monthly LinkedIn report"*:

