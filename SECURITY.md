# Security

The skills here are text files: they tell an AI assistant how to read your exports and what to recommend. They never change anything in your ad account or CRM. A security problem here looks like one of these:

- a skill that tells the assistant to change, send or delete something, although every skill is meant to be read-only
- a skill that asks for more data than its check needs, or tells the assistant to send data anywhere
- a key, password, client name, account ID or other private data committed to this repository

## Report it privately

Use **Security → Report a vulnerability** on this repository ([direct link](https://github.com/demandsense-labs/linkedin-ads-skills/security/advisories/new)). Only the maintainers can see the report. Please don't open a public issue for this.

We reply within five working days, and once it's fixed we credit you in the release notes if you want.

For a skill that is simply wrong (a bad threshold, an outdated LinkedIn setting), [open an ordinary issue](https://github.com/demandsense-labs/linkedin-ads-skills/issues/new/choose).
