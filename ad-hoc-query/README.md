## Run it in a chat

Attach your exports to a chat with Claude (or any assistant that can read a web page) and paste:

```text
Load the Ad-Hoc Query skill from https://github.com/demandsense-labs/linkedin-ads-skills/tree/main/ad-hoc-query and run it on the exports I've attached.
```

It gives recommendations only and changes nothing in your ad account or CRM.

## Run it in Claude Code

[Install the collection](../README.md#install), then call it by name or just ask for it, for example *"how did we do last week"*:

```text
/linkedin-ads-skills:ad-hoc-query
```

[`SKILL.md`](SKILL.md) holds the instructions the assistant follows.
