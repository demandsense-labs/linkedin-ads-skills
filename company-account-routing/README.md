## Run it in a chat

Attach your exports to a chat with Claude (or any assistant that can read a web page) and paste:

```text
Load the Company-level account routing scenario from https://github.com/demandsense-labs/linkedin-ads-skills/tree/main/company-account-routing and run it on the exports I've attached.
```

It gives recommendations only and changes nothing in your ad account or CRM.

## Run it in Claude Code

[Install the collection](../README.md#install), then call it by name or just ask for it, for example *"account coverage review"*:

```text
/linkedin-ads-skills:company-account-routing
```

[`SKILL.md`](SKILL.md) holds the instructions the assistant follows.
