## Run it in a chat

Attach your exports to a chat with Claude (or any assistant that can read a web page) and paste:

```text
Load the Budget Re-allocation skill from https://github.com/demandsense-labs/linkedin-ads-skills/tree/main/budget-re-allocation and run it on the exports I've attached.
```

It gives recommendations only and changes nothing in your ad account or CRM.

**To keep it in Claude.ai:** download [budget-re-allocation.zip](https://github.com/demandsense-labs/linkedin-ads-skills/releases/download/skill-files/budget-re-allocation.zip) and upload it under **Customize → Skills → Upload a skill**.
