## Run it in a chat

Attach your exports to a chat with Claude (or any assistant that can read a web page) and paste:

```text
Load the Pausing Low-Performing Ads skill from https://github.com/demandsense-labs/linkedin-ads-skills/tree/main/pausing-low-performing-ads and run it on the exports I've attached.
```

It gives recommendations only and changes nothing in your ad account or CRM.

**To keep it in Claude.ai:** download [pausing-low-performing-ads.zip](https://github.com/demandsense-labs/linkedin-ads-skills/releases/download/skill-files/pausing-low-performing-ads.zip) and upload it under **Customize → Skills → Upload a skill**.

## Run it in Claude Code

[Install the collection](../README.md#install), then call it by name or just ask for it, for example *"which ads in this campaign should I stop"*:

```text
/linkedin-ads-skills:pausing-low-performing-ads
```
